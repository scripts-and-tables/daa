# Tools track

If you need to learn a specific tool quickly — for a job, a project, an interview — follow that tool's column rather than the linear month-by-month order.

!!! note "Stub"

    Detailed reading orders land in a later pass.

## Excel

[Month 2 — Spreadsheets](../curriculum/month-02-spreadsheets/index.md) is the dedicated month. Excel also resurfaces lightly in Month 5 (Power BI imports Excel models) and Month 9 (Power Query / M is shared between Excel and Power BI).

## SQL

[Month 3 — SQL Fundamentals](../curriculum/month-03-sql-fundamentals/index.md) and [Month 4 — SQL Advanced](../curriculum/month-04-sql-advanced/index.md) are the SQL-heavy months. SQL also appears in Month 8 (modelling), Month 9 (dbt), and Month 10 (Synapse / Fabric serverless SQL).

Primary dialect: **T-SQL**. Cross-references for PostgreSQL, BigQuery, and Snowflake live in Month 4, Week 16.

## Power BI

[Month 5 — Visualization (Power BI)](../curriculum/month-05-visualization-powerbi/index.md) is the dedicated month. The data model in Month 8 transfers directly into Power BI; AutoML features from Month 11 surface in Power BI Service.

## Python

[Month 6 — Python for Analytics](../curriculum/month-06-python-pandas/index.md) is the dedicated month. Python returns in Month 7 (`scipy.stats`), Month 9 (dbt is YAML+SQL but Python is needed for adapters/macros), and Month 11 (scikit-learn).

## Azure / Microsoft Fabric

[Month 10 — Azure Data Platform](../curriculum/month-10-azure-data-platform/index.md) is the dedicated month. Azure infrastructure also underlies the Power BI Service deployment in Month 5 and the orchestration tooling in Month 9 (Azure Data Factory / Fabric Pipelines).
