# 12-month roadmap

The full Data Analytics Academy curriculum on one page. The year is structured around **five pillars** — Excel → SQL → Python → Power BI → AI — preceded by a Foundations prelude and closed by a capstone.

## Suggested cadence

- **6 hours/week** — the default. Hits ~24 hours per month, ~300 hours over the year.
- Treat the month boundary as a checkpoint: did you finish the mini-project? Can you answer the self-check questions without notes? If not, spend an extra week before moving on.

## The five pillars

- **Excel** (1 month). Lowest-friction tool, still the most common ad-hoc analytics environment. Covers Power Query (M), which transfers directly to Power BI later.
- **SQL** (2 months). The single most durable analytical skill. Fundamentals first; advanced patterns plus dimensional modelling second.
- **Python** (3 months). Highest depth in the curriculum: language + pandas, then statistical inference in code, then workflow / ETL practice. Heavy because Python is where most modern analytical careers compound.
- **Power BI** (2 months). The Microsoft-stack BI default. Core covers the canonical analyst workflow; advanced ties into Azure / Fabric and governance.
- **AI** (2 months). Classical ML for evaluating models honestly; GenAI / LLMs for using AI tools deliberately in analytical workflows.

## Outcomes by quarter

- **End of Q1 (M1–M3).** You can frame an analytical question, clean a spreadsheet, and write reasonable SQL.
- **End of Q2 (M4–M6).** You can write window functions and design a star schema; you can replace most spreadsheet work with pandas; you can defend a statistical claim in code.
- **End of Q3 (M7–M9).** You can build a small reproducible ETL pipeline; you can publish a Power BI report against Azure / Fabric data sources.
- **End of Q4 (M10–M12).** You can evaluate an ML model honestly; you can use GenAI tools in your analytical workflow without being a passenger; you have a published capstone and a certification plan.
