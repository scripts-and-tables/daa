# Curriculum

Twelve monthly themes, four weekly topics each. The sequence assumes you start from zero — feel free to skip ahead if you already have the prerequisites.

## Months

1. [Foundations](month-01-foundations/index.md) — data literacy, problem framing, math + stats intuition.
2. [Spreadsheets — Excel](month-02-spreadsheets/index.md) — formulas, pivots, Power Query.
3. [SQL Fundamentals](month-03-sql-fundamentals/index.md) — relational model, queries, joins, CTEs.
4. [SQL Advanced](month-04-sql-advanced/index.md) — window functions, performance, dialects.
5. [Visualization — Power BI](month-05-visualization-powerbi/index.md) — dataviz principles, Power BI, DAX.
6. [Python for Analytics](month-06-python-pandas/index.md) — Jupyter, pandas, plotting.
7. [Statistics for Analysts](month-07-statistics/index.md) — descriptive, inferential, A/B testing.
8. [Data Modeling & Warehousing](month-08-data-modeling-warehousing/index.md) — Kimball, star schemas.
9. [ETL/ELT & Pipelines](month-09-etl-elt-pipelines/index.md) — orchestration, dbt, data quality.
10. [Azure Data Platform](month-10-azure-data-platform/index.md) — Lake, Synapse, Fabric, Databricks.
11. [ML Fundamentals](month-11-ml-fundamentals/index.md) — supervised/unsupervised, metrics.
12. [Capstone & Soft Skills](month-12-capstone-soft-skills/index.md) — storytelling, stakeholder management, cert prep.

For a one-page summary including outcomes per quarter, see the [12-month roadmap](../roadmap/index.md).
