# Curriculum

Twelve monthly themes, four weekly topics each, organised around five pillars: **Excel → SQL → Python → Power BI → AI**.

## Months

1. [Foundations](month-01-foundations/index.md) — data literacy, problem framing, math + stats intuition. *Prelude.*
2. [Excel](month-02-spreadsheets/index.md) — formulas, pivots, Power Query. *Excel pillar.*
3. [SQL — Fundamentals](month-03-sql-fundamentals/index.md) — relational model, queries, joins, CTEs. *SQL pillar (1/2).*
4. [SQL — Advanced & Modeling](month-04-sql-advanced/index.md) — window functions, performance, star schemas. *SQL pillar (2/2).*
5. [Python — Fundamentals & pandas](month-05-python-fundamentals/index.md) — Jupyter, pandas, plotting. *Python pillar (1/3).*
6. [Python — Statistics](month-06-statistics-python/index.md) — descriptive, inferential, A/B testing. *Python pillar (2/3).*
7. [Python — Workflows & ETL](month-07-python-workflows/index.md) — APIs, pipelines, dbt, data quality. *Python pillar (3/3).*
8. [Power BI — Core](month-08-power-bi-core/index.md) — dataviz principles, model, DAX, publishing. *Power BI pillar (1/2).*
9. [Power BI — Advanced & Azure](month-09-powerbi-advanced-azure/index.md) — advanced DAX, Azure / Fabric sources, governance. *Power BI pillar (2/2).*
10. [AI — Classical ML](month-10-classical-ml/index.md) — supervised/unsupervised, metrics, AutoML. *AI pillar (1/2).*
11. [AI — GenAI & LLMs](month-11-genai-llms/index.md) — prompts, RAG, AI in analytics, AI-assisted coding. *AI pillar (2/2).*
12. [Capstone & Soft Skills](month-12-capstone-soft-skills/index.md) — storytelling, stakeholder management, cert prep. *Capstone.*

For a one-page summary including outcomes per quarter, see the [12-month roadmap](../roadmap/index.md).
