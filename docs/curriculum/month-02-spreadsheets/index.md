## Theme

Excel is still the most-used analytics tool in the world. Treating it as "just spreadsheets" leaves a huge productivity gap. This month builds *real* Excel competence — formulas that scale, pivots that summarise, and Power Query that ingests and cleans without VBA.

## Weekly plan

| Week | Topic                       | Outcome                                                              |
|------|-----------------------------|----------------------------------------------------------------------|
| 5    | Excel UI & references       | Comfortable with absolute/relative refs, named ranges, structured refs (tables). |
| 6    | Lookup & logic formulas     | `XLOOKUP`, `INDEX/MATCH`, `IFS`, text and date functions.            |
| 7    | Pivot tables & charts       | Build a pivot from a 100k-row table, slice it, chart it.             |
| 8    | Power Query (M)             | Ingest, clean, and reshape data without writing code.                |

## Prerequisites

- [Month 1 — Foundations](../month-01-foundations/index.md), particularly the data-types vocabulary and stats intuition.
- A Microsoft 365 or Excel 2021+ install (the modern functions like `XLOOKUP` are not in older versions).

## Mini-project

Take the dataset from your Month 1 memo. Move it into Excel, build a clean *Table*, write three lookup formulas that you would have done by hand last month, and produce one pivot-table summary. Save and revisit at the end of Month 6 to see how much faster the Python version is.
