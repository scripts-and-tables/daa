## Theme

Dataviz principles first, then Power BI as the primary tool. Tableau is referenced as the most common alternative; the principles transfer cleanly between them.

## Mini-project

Build a single-page Power BI report from any public dataset (the [Datasets resource page](../../resources/datasets.md) has options). Constraint: at most three charts, one filter, one KPI card. The point is restraint, not feature density.
