## Theme

Python is the second most-durable analytics skill after SQL. This month is *Python for analysts*, not *Python for software engineers* — pandas is the centre of gravity, with just enough Python to use it. The next two months ([Month 6](../month-06-statistics-python/index.md) and [Month 7](../month-07-python-workflows/index.md)) build on this foundation; the three months together form the **Python pillar**.
