## Theme

Storytelling, stakeholder management, an end-to-end capstone project, and a deliberate plan for whichever certification you are aiming at. The point of this month is to make the previous eleven *visible* — to a hiring manager, to a stakeholder, or to your future self.

## Weekly plan

| Week  | Topic                                    | Outcome                                                              |
|-------|------------------------------------------|----------------------------------------------------------------------|
| 45    | Storytelling with data                   | Knaflic / Duarte / Tufte synthesis; structure a five-slide narrative. |
| 46    | Stakeholder management & requirements    | Interviewing, prioritisation, managing scope creep, RACI.            |
| 47    | Capstone — end to end                    | One project: data → model → dashboard → narrative → published.       |
| 48    | Certification exam strategy              | Pick a target, timebox prep, drill exam objectives, book the exam.   |

## Prerequisites

- All previous months, ideally with at least one mini-project per month preserved.

## Mini-project

The capstone *is* the mini-project. Suggested constraints: real public data, a stated decision your work supports, a single Power BI report or notebook, a one-page written narrative. Publish it on GitHub; link it from your CV.

## Certification track

By this point you should have a deliberate target. The three on which the curriculum has been mapped:

- **PL-300** — Microsoft Power BI Data Analyst Associate. Best fit if Months 2–4 (Excel, SQL) and Months 8–9 (Power BI) felt natural.
- **DP-203 / DP-700** — Microsoft Azure / Fabric Data Engineer. Best fit if Months 4 (data modeling), 7 (ETL), and 9 (Azure) felt natural.
- **Google Data Analytics Certificate** — entry-level, broad, less rigorous than the Microsoft exams. Useful as a portfolio addition when starting from zero.
