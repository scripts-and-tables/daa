## Theme

Python is the second most-durable analytics skill after SQL. This month is *Python for analysts*, not *Python for software engineers* — pandas is the centre of gravity, with just enough Python to use it.

## Weekly plan

| Week  | Topic                                | Outcome                                                              |
|-------|--------------------------------------|----------------------------------------------------------------------|
| 21    | Python basics + Jupyter + venvs      | Comfortable in a notebook; create and activate a virtual environment. |
| 22    | numpy & pandas core                  | DataFrames, Series, indexing, `.loc`/`.iloc`, basic aggregation.     |
| 23    | Cleaning, joining, reshaping         | `merge`, `groupby`, `pivot_table`, `melt`, missing-value handling.   |
| 24    | Plotting — matplotlib / seaborn / plotly | Build the same chart in all three; know when each is appropriate. |
