# Tools track

If you need to learn a specific tool quickly — for a job, a project, an interview — follow that tool's column rather than the linear month-by-month order.

!!! note "Stub"

    Detailed reading orders land in a later pass.

## Excel

[Month 2 — Excel](../curriculum/month-02-spreadsheets/index.md) is the dedicated month. Excel also resurfaces lightly in [Month 8 — Power BI Core](../curriculum/month-08-power-bi-core/index.md) (Power BI imports Excel models) — and the Power Query / M engine you learn in Month 2, Week 8 is the same engine used in Power BI in Month 8.

## SQL

[Month 3 — SQL Fundamentals](../curriculum/month-03-sql-fundamentals/index.md) and [Month 4 — SQL Advanced & Modeling](../curriculum/month-04-sql-advanced/index.md) are the SQL-heavy months. SQL also appears in [Month 7](../curriculum/month-07-python-workflows/index.md) (dbt) and [Month 9](../curriculum/month-09-powerbi-advanced-azure/index.md) (Synapse / Fabric serverless SQL).

Primary dialect: **T-SQL**. Cross-references for PostgreSQL, BigQuery, and Snowflake live in Month 4, Week 15.

## Power BI

[Month 8 — Power BI Core](../curriculum/month-08-power-bi-core/index.md) and [Month 9 — Power BI Advanced & Azure](../curriculum/month-09-powerbi-advanced-azure/index.md) are the Power BI months. The data model from [Month 4](../curriculum/month-04-sql-advanced/index.md) transfers directly into Power BI; AutoML features from [Month 10](../curriculum/month-10-classical-ml/index.md) surface in Power BI Service; Copilot features from [Month 11](../curriculum/month-11-genai-llms/index.md) ship inside Power BI itself.

## Python

[Month 5 — Python Fundamentals & pandas](../curriculum/month-05-python-fundamentals/index.md), [Month 6 — Python Statistics](../curriculum/month-06-statistics-python/index.md), and [Month 7 — Python Workflows & ETL](../curriculum/month-07-python-workflows/index.md) are the three Python months. Python returns in [Month 10](../curriculum/month-10-classical-ml/index.md) (scikit-learn) and [Month 11](../curriculum/month-11-genai-llms/index.md) (LLM APIs, RAG).

## Azure / Microsoft Fabric

[Month 9 — Power BI Advanced & Azure](../curriculum/month-09-powerbi-advanced-azure/index.md) is the dedicated Azure month. Azure infrastructure also underlies the dbt + orchestration tooling in [Month 7](../curriculum/month-07-python-workflows/index.md) (Azure Data Factory / Fabric Pipelines) and the LLM APIs in [Month 11](../curriculum/month-11-genai-llms/index.md) (Azure AI / Azure OpenAI Service).

## AI tools (LLMs, Copilot)

[Month 11 — AI: GenAI & LLMs](../curriculum/month-11-genai-llms/index.md) is the dedicated month. Microsoft Copilot features ship inside Power BI ([Month 8](../curriculum/month-08-power-bi-core/index.md)), Excel ([Month 2](../curriculum/month-02-spreadsheets/index.md)), and Fabric ([Month 9](../curriculum/month-09-powerbi-advanced-azure/index.md)); Month 11 covers them in depth alongside the underlying LLM APIs.
