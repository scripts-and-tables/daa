# Certifications track

This page maps the three certifications the curriculum is designed to support back into the months and weeks where you will pick up the relevant skills.

!!! note "Stub"

    Detailed exam-objective mapping lands in a later pass. The high-level mapping below is correct.

## PL-300 — Microsoft Power BI Data Analyst Associate

The flagship certification for analysts on the Microsoft stack.

| Exam domain (approx. weighting) | Curriculum coverage |
|---------------------------------|---------------------|
| Prepare the data (~25%)         | [Month 2 — Excel](../curriculum/month-02-spreadsheets/index.md), [Month 3 — SQL Fundamentals](../curriculum/month-03-sql-fundamentals/index.md) |
| Model the data (~25%)           | [Month 8 — Data Modeling & Warehousing](../curriculum/month-08-data-modeling-warehousing/index.md) |
| Visualize and analyze (~25%)    | [Month 5 — Visualization (Power BI)](../curriculum/month-05-visualization-powerbi/index.md) |
| Deploy and maintain (~25%)      | [Month 5, Week 20 — Publishing & RLS](../curriculum/month-05-visualization-powerbi/index.md) |

Official: [PL-300 exam page](https://learn.microsoft.com/en-us/credentials/certifications/exams/pl-300/).

## DP-203 / DP-700 — Microsoft Azure / Fabric Data Engineer Associate

DP-203 is being refreshed/replaced by DP-700 as Microsoft Fabric becomes the primary platform — confirm the current exam ID before booking.

| Exam domain (approx.)        | Curriculum coverage |
|------------------------------|---------------------|
| Design and implement storage | [Month 10 — Azure Data Platform](../curriculum/month-10-azure-data-platform/index.md) |
| Develop data processing      | [Month 9 — ETL/ELT & Pipelines](../curriculum/month-09-etl-elt-pipelines/index.md) |
| Secure, monitor, optimize    | [Month 10, Week 40 — Cost, security, governance](../curriculum/month-10-azure-data-platform/index.md) |

Official: [Microsoft Learn — Data Engineer career path](https://learn.microsoft.com/en-us/training/career-paths/data-engineer).

## Google Data Analytics Professional Certificate

Entry-level, broader, less rigorous than the Microsoft exams. Best as a portfolio addition for someone with no prior data background.

| Course           | Curriculum coverage |
|------------------|---------------------|
| Foundations      | [Month 1 — Foundations](../curriculum/month-01-foundations/index.md) |
| Ask questions    | [Month 1, Week 2 — Problem framing](../curriculum/month-01-foundations/week-02-problem-framing.md) |
| Prepare data     | [Month 2 — Spreadsheets](../curriculum/month-02-spreadsheets/index.md) |
| Process data     | [Month 3 — SQL Fundamentals](../curriculum/month-03-sql-fundamentals/index.md) |
| Analyze data     | [Month 7 — Statistics for Analysts](../curriculum/month-07-statistics/index.md) |
| Share data       | [Month 5 — Visualization (Power BI)](../curriculum/month-05-visualization-powerbi/index.md) |
| Data analysis with R | *Out of scope for DAA's Python-first track.* |
| Capstone         | [Month 12 — Capstone & Soft Skills](../curriculum/month-12-capstone-soft-skills/index.md) |

Official: [Google Data Analytics Certificate on Coursera](https://www.coursera.org/professional-certificates/google-data-analytics).
